# Timeline and activity

This page is for anyone using Invy. It explains how Invy remembers what happened to each item and where it has been.

Invy writes down everything that happens to an item: when it was added and where, each move, each change to its
details (what it was before and after), each change to a counted amount, photos added, when it was seen, marked
missing or found again by an [audit](audits.md), and when it was disposed of or restored.
Nothing is ever taken out of the timeline.

## An item's timeline

Open an item on **Browse**. At the bottom:

- **Where it has been** lists each place it has been, newest first, with when it got there and when it left. It
  counts its containers' moves too: if box F went from the shed to the garage, the baseball inside it went with it,
  and its list says so.
- **Timeline** lists what happened to it, newest first. On a container it also lists what went in and came out.

## Activity

The **Activity** tab lists everything that happened in the space, newest first, with who did it. Press
**Show older** for more.
