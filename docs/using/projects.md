# Projects

This page is for anyone who builds, repairs or makes things: it shows how to set aside what a project needs, use
it up, and finish the project.

Projects show while the space has the **Projects** feature on (**Settings → Kind and features**). See
[Spaces](spaces.md#features).

## Start a project

On **Views**, open **Projects**, write its name under **New project**, such as *Build a bookshelf*, and press
**Start**.

## Set things aside

1. Open the thing on **Browse**.
2. Press **Set aside for a project**.
3. Pick the **Project**, or **A new project…** to start one.
4. For a counted thing, enter **How much**. A single thing is set aside whole.
5. Press **Set aside**.

Setting aside doesn't change the amount. It does count against [low stock](stock.md), and nothing can be set aside
twice over: only what isn't already set aside for another project is free. In search, `project:bookshelf` finds what
the project sets aside.

## Use it up, or release it

On the project, or on the thing's page:

- **Used up** takes what was set aside off a counted thing's amount, or marks a single thing disposed of. The
  timeline records it.
- **Release** gives it back without using any.

## Finish

**Finish** marks the project done and releases whatever it still set aside. **Remove** deletes the project the same
way; what it used up stays used up. Tick **Show finished projects** to see done ones.

## If something goes wrong

- **"Only … isn't set aside already".** Other projects have the rest. Release some there, or set aside less.
- **"… is a single item: set it aside whole".** Single things are set aside as 1.
